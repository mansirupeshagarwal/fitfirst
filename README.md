# Fit First website: starter files

Plain HTML, CSS and JavaScript. No build step. Open `index.html` in a browser to preview.

## Files

- `index.html` is the homepage.
- `fit-finder.html` is the size quiz. It uses vanilla JavaScript.
- `images/` holds placeholder photos. Replace them with your own shoot before launch, and check each licence.

## Still placeholders

- Founder text in the "Why Fit First" section.
- The waitlist forms. Both buttons currently do nothing. Connect them to an email tool such as Klaviyo, Mailchimp or Shopify Forms.
- Social links in the footer, the WhatsApp number and the measuring video link.
- The heart ("I want this one first") buttons. Votes need to be saved somewhere, for example a form tool or a small database.
- The "Clothing" checkbox on the waitlist form.

## Design rules

- Font: Instrument Sans (Google Fonts). Handwritten notes use Caveat.
- Colours:
  - Text: #141414
  - Muted text: #5A5C63
  - Light grey sections: #F3F4F6
  - Accent: cobalt #2340C8
  - Sticker: #E0342C
- Buttons are pill-shaped, with uppercase text spaced 0.14em apart.
- Headings are regular weight, never bold.
